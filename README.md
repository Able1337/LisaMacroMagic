# Lisa’s Macro Magic 🎀 — 0.5.16

Портативный редактор макросов Windows x64. Python, интернет и права администратора
на целевом компьютере не нужны. Версии 0.1 и 0.5 остаются отдельно.

## Что изменилось

Начиная с 0.5.16 после обновления файл называется `LisaMacroMagic.exe`, без номера
версии. Номер по-прежнему виден в окне и на GitHub. При переходе с прежнего
обновлятора приложение может перезапуститься ещё раз, чтобы сменить имя.
Существующий соседний `LisaMacroMagic.exe` не перезаписывается при переименовании.
Ярлык со старым именем файла нужно один раз направить на `LisaMacroMagic.exe`.

0.5.15 — тестовый релиз для проверки обновления из 0.5.14, без новых функций.

В 0.5.14 EXE обновления загружается через тот же сетевой компонент Qt, что и сведения о релизе. При сбое можно открыть страницу релизов для ручной загрузки. Для перехода с 0.5.12–0.5.13, если загрузка не работает, скачай этот EXE вручную.

0.5.13 — тестовый релиз для проверки обновления из 0.5.12, без новых функций.

В 0.5.12 приложение проверяет публичные GitHub Releases при запуске. Кнопка
«Обновить» запускает проверку вручную. После согласия загружается EXE, проверяются
размер и SHA-256 из GitHub, затем приложение закрывается, заменяет текущий файл
и запускается снова. Папка EXE должна быть доступна для записи. Ошибка загрузки
не меняет текущую версию; при ошибке замены или запуска помощник восстанавливает
предыдущий файл. Настройки и сценарии сохраняются отдельно и не заменяются.
Проверка не отправляет сценарии и не требует аккаунта GitHub.

Пасхалка «date idea?» теперь содержит ссылку на Telegram @Able_ebg.

Для следующего релиза обнови версию в исходниках, прогони `build.bat`, отправь
исходники в репозиторий и опубликуй стабильный GitHub Release с тегом `vX.Y.Z`
и файлом `LisaMacroMagic.exe`. Для клиентов 0.5.12–0.5.15 можно приложить тот же
бинарник под именем `LisaMacroMagic_vX.Y.Z.exe`. Проверка использует [GitHub Releases API](https://docs.github.com/en/rest/releases/releases).

Крестик в 0.5.11 убирает окно в системный трей Windows рядом с часами.
Горячие клавиши сохраняют своё состояние. Нажми на значок лисички, чтобы открыть
окно, либо выбери «Открыть» или «Выйти» в его меню. Если значок не виден, проверь
скрытые значки под стрелкой `^`. «Выйти» останавливает выполнение и завершает
приложение. Если системный трей недоступен, крестик закрывает приложение как обычно.
Приложение остаётся обычным процессом пользователя, без службы и автозапуска.

В 0.5.11 убрана постоянная надпись под мотивашкой. Фраза «Лисичка шепчет
секреты в 12:00 и 18:00… ♡» добавлена 61-м элементом коллекции и участвует
в обычном случайном выборе. Тот же текст виден при наведении на Made with love ♡.

В коллекции 61 фраза: 60 выпадают случайно без повторов за запуск, а подсказка
«7 кликов за 4 секунды» появляется по прежнему расписанию — в первые 10 минут
00, 06, 12 и 18 часов. Обычные фразы меняются на отметках :00, :10, :20 и т. д.
системных часов Windows. После исчерпания случайного списка остаётся последняя
обычная фраза; при перезапуске список перемешивается заново.

Остальные функции сохранены: несколько сценариев с разными биндами, клавиши,
мышь, ожидание ручного клика или клавиши (space = пробел), запись действий,
Input Monitor, обе темы, анимированная лисичка без серого фона и пасхалка
«👫 🇯🇵 — date idea?» по семи кликам за четыре секунды в простое.

Латинские буквы и цифры отправляются кодами клавиш Windows. Для ввода в текстовое
поле результат зависит от раскладки: клавиша Z/Я напечатает z или я. Windows-
раскладка не переключается. Управляющая клавиша (изначально F12) настраивается;
в простое она переключает бинды, при записи/выполнении останавливает действие.

Задержка старта — 0–60 секунд, подготовки записи — 1–60 секунд. Настройки,
тема и сценарии автоматически сохраняются в Документы / LisaMacroMagic /
settings.json и загружаются при старте. Бинды после запуска выключены.

## Быстрый старт

### Встроенный Input Monitor (0.5.11)

Кнопка **«⌨ Input Monitor»** внизу главного окна открывает тестовое окно.
Кликни в поле проверки, включи бинды и запусти сценарий из этого окна.
Журнал показывает нажатия и отпускания клавиш, сочетания с Ctrl/Alt/Shift,
VK и scan-коды, автоповтор, кнопки мыши (ЛКМ/ПКМ/средняя/X1/X2), двойные клики,
прокрутку, координаты и время событий. Tab и полученные сочетания фиксируются
без выполнения обычных команд окна.

Есть очистка и копирование журнала. В памяти отображается до 5000 строк,
журнал не сохраняется в JSON и не отправляется по сети. Записываются только
события самого видимого окна монитора, а не других приложений. При закрытии
монитора наблюдение прекращается; повторная кнопка открывает то же окно.
Тема совпадает с темой приложения. Закрытие главного окна закрывает монитор.

Макросы и запись допускаются в Input Monitor, но по-прежнему запрещены в главном
редакторе. Бинды запуска и управляющая клавиша перехватываются приложением и в
журнал монитора не попадают. Системные перехваченные Windows сочетания тоже могут
не дойти до окна. Физический и программно сгенерированный ввод в журнале не
различается: он показывает то, что окно фактически получило.

1. Открой `LisaMacroMagic.exe`.
2. Слева выбери сценарий или создай новый. Укажи имя и бинд, нажми «Применить».
3. Добавляй шаги, редактируй их двойным кликом, переставляй стрелками ↑/↓.
4. Включи бинды флажком или управляющей клавишей (изначально F12).
5. При задержке **0 с** запускай бинд сценария прямо из нужного окна браузера.
   Для кнопки «Запустить» задай задержку больше нуля и переключись в браузер за это время.
6. Во время выполнения управляющая клавиша останавливает сценарий.
   Следующее отдельное нажатие в простое переключит бинды.

Например, F6: `Z → ждать ручной ЛКМ → Enter → Ctrl+Shift+S`,
а F7: другой сценарий. У каждого сценария свой бинд. «Копия» копирует шаги без бинда.
Одновременно работает один сценарий, каждый запуск выполняет один проход.
Примеры находятся в `examples.json`; они не запускаются автоматически.
Сочетания из примера не проверены как реальные команды Roadcons.

## Настройки и автосохранение

Стандартный путь:

`Документы\LisaMacroMagic\settings.json`

Используется системная папка Documents, включая перенаправленную Windows папку.
При отсутствии файла программа создаёт его с начальными настройками.
При наличии валидного файла сразу загружает настройки и сценарии.
Сохраняются задержки, управляющая клавиша, тема, названия, бинды и шаги всех сценариев.
Флажок включения биндов при каждом запуске выключен.

Изменения автоматически записываются примерно через 0.7 секунды после редактирования,
также при закрытии. Название и бинд должны быть валидными: некорректный черновик
не заменяет последний исправный файл. Бинд и управляющую клавишу нужно применить,
чтобы они начали действовать в текущем сеансе.
Запись сохраняется после её завершения, а не посреди перехвата ввода.
При ошибке доступа в статусе появится причина; можно воспользоваться «Сохранить как…».

«Сохранить» записывает стандартный файл без выбора пути.
«Сохранить как…» экспортирует копию; автосохранение остаётся по стандартному пути.
«Открыть JSON» импортирует проект, выключает бинды и сохраняет импорт в стандартный файл.
Старые JSON версии 0.5 без настроек поддерживаются; им присваиваются новые значения по умолчанию.
Повреждённый стандартный файл **не перезаписывается автоматически**. Для его замены
нужно явно нажать «Сохранить» и подтвердить замену, либо экспортировать копию в другое место.
Запускай один экземпляр приложения, чтобы два окна не сохраняли один файл одновременно.

## Бинды

Поддерживаются F1–F12, Ctrl/Alt/Shift с латинской буквой, цифрой или функциональной клавишей.
Примеры: `F6`, `Ctrl+Alt+K`, `Ctrl+Shift+F11`.
Управляющее сочетание не может совпадать с биндом сценария. У сценариев бинды тоже уникальны.
После редактирования поля «Управление» нажми «Применить» рядом с ним.

Горячие клавиши определяются по физическим Windows VK, а не по текущей раскладке.
Отслеживается только текущее состояние настроенных клавиш и модификаторов;
история ввода в простое не сохраняется. Сработавшая комбинация не передаёт свою
основную клавишу браузеру. При выключенных биндах остаётся только управляющая комбинация.
Программно сгенерированный ввод не запускает бинды повторно.
Сочетания других программ и системные ограничения не перехватываются принудительно;
автоматического определения всех внешних конфликтов нет. Выбирай свободные комбинации.

## Шаги

| Шаг | Поведение |
| --- | --- |
| Клавиша / сочетание | `z`, `enter`, `ctrl+shift+s` |
| Пауза | 0.01–600 секунд |
| Ждать ручной ЛКМ | Продолжает после нажатия и отпускания ЛКМ, с таймаутом |
| Ждать нажатия клавиши | Например `space`: ждёт ручной пробел и его отпускание, с таймаутом |
| Клик / перемещение | Абсолютные экранные координаты X/Y |
| Прокрутка | Количество шагов по X/Y, отрицательное Y — вниз |
| Клавиша / мышь вниз / вверх | Подробные события записи, включая перетаскивания |

Дополнительные имена клавиш: `tab`, `space`, `esc`, `backspace`, `delete`, `insert`,
`home`, `end`, `page_up`, `page_down`, `up`, `down`, `left`, `right`.
Запись может содержать `vk:90` — клавишу Windows. Раскладка влияет на получаемый
текст в полях ввода; буквы макросов и сочетания отправляются кодами клавиш.

## Запись и остановка

Выбери сценарий, нажми «Записать действия», подтверди и переключись в нужное окно
за заданное время подготовки. Записываются клавиши, кнопки мыши, движения,
прокрутка и паузы. Не вводи пароли или личные данные: события клавиш могут их раскрывать.
Управляющая клавиша завершает запись и добавляет её в конец сценария.
Движения ограничены примерно 12 событиями в секунду. Лимит — 10 минут или около
10000 шагов. Программно сгенерированные события не записываются.

При смене активного окна запись и воспроизведение останавливаются.
Окно сохранения или отдельный диалог браузера тоже могут считаться сменой окна.
После остановки/ошибки программа отпускает удерживаемые ею клавиши и кнопки мыши.
При принудительном завершении процесса очистку гарантировать нельзя.
Между проверкой фокуса и отправкой события остаётся небольшой интервал;
обычная имитация ввода не гарантирует абсолютной адресации при перехвате фокуса.

## Roadcons

Сценарии настраивает Лиса. Программа не обращается к Roadcons по сети,
не распознаёт объекты карты и не проверяет результат действий страницы.
Выбор объекта можно оставить ручным шагом, для медленных действий добавить паузу.
Координаты зависят от окна, мониторов, разрешения, масштаба и прокрутки.
Первый прогон проверяй на безопасном примере без реальных изменений.

Приложение не запрашивает UAC, не создаёт службы или автозагрузку,
не меняет системные настройки и не обходит защищённые окна/политики.
При блокировке Windows зафиксируй сообщение и обратись к администратору.
EXE не подписан цифровой подписью.

## Сборка и исходники

На компьютере сборки нужен Python 3.12 x64 под Windows. Запусти `build.bat`.
При отсутствии `py` сначала задай `LISA_PYTHON` — полный путь к Python.
Скрипт создаст локальную `.venv`, установит `requirements.txt`, выполнит тесты
и соберёт `dist\LisaMacroMagic.exe`. Интернет нужен только для установки
зависимостей на машине сборки; готовый EXE автономен.

Сборка PyInstaller: onefile, windowed, noupx, icon и assets включены внутрь EXE.
Тесты: `.venv\Scripts\python.exe -m unittest discover -s tests -v`.
Исходник: `.venv\Scripts\python.exe app.py`.
PySide6/Qt: LGPLv3/GPLv3 или коммерческая лицензия; pynput: LGPLv3;
Python: PSF; PyInstaller: GPLv2 с исключением для собранных приложений.
Доступные тексты лицензий зависимостей находятся в `licenses/`.
GIF предоставлен пользователем; в окне отображается верхняя средняя ячейка
спрайтового листа. Три точных цвета клетчатого фона и его дизеринга становятся прозрачными при
отрисовке, остальные пиксели лисички сохраняются. ICO подготовлен из первого
прозрачного кадра. Исходный GIF не изменён.

Справка: https://doc.qt.io/qtforpython-6/PySide6/QtCore/QStandardPaths.html
и https://pynput.readthedocs.io/en/latest/keyboard.html

В 0.5.11 также удалён третий серый оттенок дизеринга, который оставлял мелкие точки вокруг лисички. Розовые декоративные искры сохранены.

Таблица VK Windows: https://learn.microsoft.com/en-us/windows/win32/inputdev/virtual-key-codes
